자동 테스트: 26개, 실패 0, 오류 0, 건너뜀 0.

## 실제 학습·평가

M5 CA_1 매장 120개 상품(고정 시드42), 90,960개 일별 기록. 최근730일에 이력 계산용28일을 추가해서 읽었습니다. 기존 관측 0은 유지했고 결측 0 대체는 하지 않았습니다.

학습 target 상한: 2016-04-24. 평가 예측 기준일: 2016-04-24~2016-05-20(27회, 상품120개, horizon별3,240건).
내일과 모레 모두 같은 기준일에서 예측합니다. 각 평가일의 7일 평균을 다시 계산하며 두 방법의 대상 행은 동일합니다. 평가 모델은 고정하고, 이전 평가일의 관측 판매는 다음 기준일에만 이용합니다.

| 예측 | XGBoost MAE | 7일 평균 MAE | MAE 감소 | XGBoost RMSE | 7일 평균 RMSE |
|---|---:|---:|---:|---:|---:|
| d1 | 1.0565 | 1.0925 | 3.30% | 2.0556 | 2.0533 |
| d2 | 1.0704 | 1.1127 | 3.81% | 2.0900 | 2.1199 |

MAE는 양쪽 모두 개선됐지만 d1 RMSE는 기준보다 조금 높습니다. 모든 지표에서 우수하다고 볼 수 없습니다. 원본 상세 수치는 artifacts/evaluation.json, 예측별 값은 artifacts/validation_predictions.csv에 있습니다.

제공 모델은 위 평가를 마친 뒤 2016-05-22까지 재학습했습니다. 전체 M5 공식 WRMSSE 또는 한국 매장 성능을 평가한 결과가 아닙니다. 120개 상품의 단일 기간 시험으로 운영 성능을 보장하지 않습니다.

## 기능·통합 검증

- SRS 예제: 16+12+10−15=23 → 24개/4박스, 도착 전 부족13.
- 음수 필요량0, 정확한 박스 배수, 소수 예측, 잘못된 입력 거부.
- 실제 M5 요청 → 모델 추론 → 추천 초안 생성 → 승인 API까지 통과.
- 결측일·품절·휴무는 수요0으로 채우지 않음. 미래 판매 변경 시 d1/d2 입력 불변.
- 다른 매장 초안 조회/승인 차단, 조회전용역할 승인 차단.
- 중복 생성 키, 반복/동시 승인 처리, DB 재연결 후 영속성 확인.
- 승인자·+09:00 시각·수량 저장, 승인 후 재고/입고/추천/전송여부 불변.
