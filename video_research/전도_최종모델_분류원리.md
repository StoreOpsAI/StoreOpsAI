# 전도 최종모델: 관절 정규화부터 경보까지

현재 배포 폴더 `analysis/`의 **v2 모델**을 기준으로 설명한다. 이 모델이 찾는 것은 순간적으로 넘어지는 동작 자체가 아니라 **바닥에 누워 있는 사람**이다. 서 있던 기록은 요구하지 않는다.

> **한 줄 요약:** YOLO Pose가 사람의 관절을 찾고 → 관절 좌표를 사람 크기 기준으로 바꾸고 → MLP가 그 자세의 누움 점수를 내고 → 같은 자리에서 1초 이어지면 경보를 낸다.

## 1. YOLO Pose가 먼저 하는 일

영상을 약 **초당 3장(3fps)** 확인한다. 각 장에서 사전학습된 `yolo11s-pose.pt`가 사람마다 다음 값을 뽑는다.

- 사람 박스: 화면에서 사람이 차지하는 사각형 `(x1, y1, x2, y2)`
- 관절 17개의 `(x, y)` 위치와 각 관절의 검출 신뢰도

YOLO Pose의 역할은 **관절을 찾는 것**이다. 여기서 곧바로 “전도”를 결정하지 않는다.

## 2. 관절값을 어떻게 정규화하나?

화면의 원래 좌표를 그대로 쓰면, 같은 자세여도 사람의 **화면 위치와 찍힌 크기**에 따라 숫자가 크게 달라진다. 그래서 관절마다 아래처럼 바꾼다.

```text
정규화 x = (관절 x - 사람 박스 중심 x) / 사람 박스의 긴 변
정규화 y = (관절 y - 사람 박스 중심 y) / 사람 박스의 긴 변
```

예를 들어 박스 중심이 `(200, 300)`, 긴 변이 `400`픽셀, 어깨가 `(220, 180)`이면 어깨의 새 좌표는 `(0.05, -0.30)`이다. 이는 **“화면의 (220, 180)에 있다”**가 아니라 **“그 사람 중심보다 조금 오른쪽, 위쪽에 있다”**는 뜻이다.

이렇게 하면 화면의 다른 위치에 서거나 더 크게 찍혀도 비슷한 자세는 비슷한 좌표로 표현된다. 다만 **실제 체형 차이나 원근에 따른 관절 검출 오류까지 없애지는 못한다.**

관절 신뢰도가 **0.3 미만**이면 해당 관절의 정규화 좌표를 `0`으로 넣는다. 신뢰도 값 자체는 버리지 않는다. 양쪽 어깨와 양쪽 엉덩이가 모두 확인될 때만 어깨 중심에서 엉덩이 중심으로 향하는 **몸통 방향**을 계산하고, 하나라도 부족하면 몸통 방향값 3개를 `0`으로 넣는다. 따라서 엉덩이가 안 보이더라도 다른 관절과 박스 정보로 점수는 낼 수 있지만, 판단 근거가 줄어든다.

## 3. MLP에는 어떤 숫자가 들어가나?

사람 한 명을 다음 **56개 숫자**로 표현한다.

| 입력 | 개수 | 의미 |
| --- | ---: | --- |
| 관절 17개의 정규화된 x, y | 34 | 관절이 사람 중심에서 어느 방향에 놓였는가 |
| 관절 17개의 신뢰도 | 17 | 각 관절을 얼마나 확실하게 찾았는가 |
| 박스 높이/너비, 너비/높이 | 2 | 화면에서 몸의 가로·세로 모양 |
| 몸통 방향 x, y와 계산 가능 여부 | 3 | 어깨와 엉덩이의 상대 방향 |
| **합계** | **56** | |

MLP에 넣기 직전에는 각 숫자를 다시 `(값 - 학습 데이터 평균) / 학습 데이터 표준편차`로 바꾼다. 평균·표준편차는 **학습 데이터에서만 계산해 모델과 함께 저장**하며, 실행할 때도 같은 값을 사용한다. 첫 번째 정규화는 **사람의 위치·크기 차이를 줄이는 작업**, 두 번째는 **서로 범위가 다른 숫자들을 MLP가 다루기 쉽게 맞추는 작업**이다.

## 4. MLP는 무엇을 보고 ‘누움’을 배우나?

MLP는 `56 → 128 → 64 → 2` 구조의 작은 신경망이다. 마지막 두 출력은 **정상**과 **누움**에 해당한다. 학습 과정에서 예시의 정답을 보고 내부 가중치를 조정하므로, 실행 시에는 새 사람의 관절 배치가 학습한 누움 패턴에 얼마나 가까운지 점수로 낸다.

학습 정답은 전도 영상의 시간 라벨과 사람 박스로 만들었다.

- 전도 시작 **5초 이전**의 사람: 정상
- 전도 시작 **5초 이후**, 전도 대상 박스와 충분히 겹치는 사람: 누움
- 전도 전후 전환 구간과 대상이 애매한 사람: 학습에서 제외
- 별도 매장이동 정상 영상의 사람: 정상

예를 들어 다리와 몸통이 펼쳐진 모양, 어깨·엉덩이·무릎의 상대 위치, 박스의 가로·세로 비율 등이 **함께** 입력된다. MLP가 이 값들의 조합을 학습한다. **“몸통 각도가 몇 도 이상이면 누움” 같은 단일 고정 규칙은 없다.** 화면에서 수평·수직으로 보이는 방향은 단서지만, 카메라 쪽으로 누우면 2D 화면에서는 세로로 보일 수도 있다.

최종 가중치는 전도 원본 **321클립**, 매장이동 정상 원본 **32클립**, train 전용 열화 증강 **353클립**으로 학습했다. 증강은 해상도·블러·밝기·대비·JPEG 품질을 바꾼 영상에서 포즈를 다시 뽑은 것이다. 공식 validation에는 증강을 적용하지 않았다. 모델은 60에폭, 시드 0, 클래스 균형 가중 손실로 학습했다.

## 5. 점수에서 경보까지

MLP가 사람마다 `0~1`의 **누움 점수**를 낸다. 이는 보정된 실제 확률이 아니다. 현재 배포 설정은 다음과 같다.

```text
누움 점수 ≥ 0.5
    → 그 프레임의 누움 후보
    → 다음 프레임에서도 같은 자리의 후보인지 박스 IoU ≥ 0.3으로 연결
    → 1초 이상 이어지면 전도 경보 1회
```

3fps에서 1초 유지는 처음 관측한 표본과 경보 표본의 간격이 1초 이상이라는 뜻이다. 연속 표본이라면 보통 **첫 표본을 포함해 4개 표본**이 필요하다. 중간에 후보가 한 표본 빠지는 것은 허용한다. 추적 ID 대신 박스의 겹침으로 이어 붙이므로, 사람이 넘어질 때 ID가 바뀌어도 경보를 이어갈 수 있다.

따라서 역할을 나누면 **YOLO Pose는 관절 검출**, **정규화는 입력 정리**, **MLP는 한 장면의 자세 분류**, **1초 유지 로직은 경보 결정**이다.

## 6. 어디까지 확인됐나?

현재 v2의 공식 validation 기록에는 전도 클립 **81/81 적중**, 사람 단위 누움 **precision 0.953 / recall 0.999 / F1 0.975**가 있다. 한편 매장이동 정상 영상에서는 **505.6분에 오경보 14건**이 나왔다. 높은 정확도 수치만으로 실사용 오경보가 적다고 말할 수 없는 이유다.

또한 v2는 이전 v1 평가에 쓴 공식 validation을 **재사용**했다. 따라서 v2 수치는 독립적인 최종 시험 성적으로 볼 수 없다. 학습·평가 영상은 높은 위치에서 내려다보는 CCTV 장면이고, **정면 웹캠이나 모든 체형·거리에서의 성능은 검증되지 않았다.** 정규화를 하지 않은 모델과의 직접 비교도 없으므로, 정규화만으로 성능이 얼마나 올랐는지는 알 수 없다.
