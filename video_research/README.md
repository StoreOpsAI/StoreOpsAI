# 영상 모델링 연구 (video_research)

> StoreOpsAI의 영상 기반 이상행동 인식 모델 연구와 개발 과정입니다. 서비스 연동 코드는 `storeops_ai/`(루트)에 있고, 이 폴더는 학습·평가 파이프라인과 의사결정 기록입니다.

무인 매장 CCTV 영상에서 **쓰러짐(전도)·유기·절도** 같은 이상행동이 일어났는지를 찾아 알림을 보내는 시스템의 인식 모델과 개발 과정입니다.
목표는 사람을 구별하거나 다시 찾는 것이 아니라 **행동 자체**를 인식하는 것입니다.

- 모델: 사람 추적(YOLO11n) → S3D 영상 분류기 2개(화면 전체 A, 사람 크롭 C1) → 동적 결합 → 이진 경보
- 평가: AI Hub 공개 데이터, 날짜 단위 5-fold OOF와 공식 validation 1회(동결 후)
- 이 폴더에는 **학습 가중치와 원본 데이터를 올리지 않았습니다**(AI Hub 이용 약관 확인 전, 용량). 서비스가 쓰는 가중치의 해시는 연동 브랜치의 `WEIGHTS.sha256`에 있습니다.

## 결과 (최종 서비스 구성)

공식 validation 342개 영상(전도 81, 유기 80, 절도 80, 매장이동 101)의 이벤트 단위 결과입니다. 이벤트 재현율 0.9 목표로 날짜 5-fold OOF에서 임계값을 정하고 동결했습니다.

| 행동 | Event Precision | Event Recall | Event F1 | 오경보/시간 (엄격: 다른 행동 영상의 경보도 오경보) |
|---|---|---|---|---|
| 전도 | 1.000 | 0.889 | 0.941 | 0.00 |
| 유기 | 0.941 | 0.887 | 0.913 | 0.81 |
| 절도 | 0.867 | 0.775 | 0.818 | 1.28 |
| 평균 | | | **0.891** | |

- 정상을 "걷기·서 있기" 영상만으로 잡은 보조 기준에서는 평균 Event F1 0.918입니다.
- 개발용 OOF 평균 Event F1은 0.936, 학습(재대입)은 0.988이라 **학습 → 안 본 날짜로 갈 때 성능이 내려갑니다**(OOF와 공식 validation의 차이 약 0.045).
- **6클래스(전도·유기·절도·파손·방화 + 정상)로 확장 중입니다.** 아직 서비스에는 들어가 있지 않고, 결과는 위 표에 포함하지 않았습니다.

### 알려진 한계 (결과와 항상 같이 밝힙니다)
1. **공식 validation을 여러 번 봤습니다**(결합 방식·전도 임계값을 정하며 3회). 완전한 blind 평가가 아닙니다.
2. 공식 validation의 정상은 매장이동(걷기·서 있기)뿐이라 반품·손 전달 같은 어려운 정상이 없어 오경보가 낙관적입니다. 임계값을 안 본 fold에서 평가한 개발용 OOF 오경보(전도 1.84, 유기 2.60, 절도 2.33/시간, 재현율 0.90~0.94)가 더 보수적인 참고치입니다.
3. **같은 매장·다른 날짜** 평가라서 새 장소에서의 성능은 측정되지 않았습니다. 강의실 웹캠에서는 유기가 뜨지 않았습니다.
4. 절도는 정상 쇼핑의 "물건 집기"와 겉모습이 비슷해 오경보가 가장 많습니다(후보 알림 수준).
5. 최종 모델은 전체 개발 데이터로 학습해서 OOF가 없고, 임계값은 fold 모델 OOF로 정했습니다.
6. (확장 중인 6클래스) 파손·방화는 날짜 격리를 하지 못했고, 정상 창 일부는 Claude가 눈으로 검수한 것이며 **사람 검수가 아닙니다**.

## 개발 과정에서 지킨 원칙

- **누수 방지:** 한 영상에서 만든 모든 창과 같은 촬영 회차·다중 카메라는 같은 split에 둡니다. 창 단위 무작위 분할은 하지 않습니다. 증강은 학습에만 적용합니다.
- **임계값은 측정으로:** 임의 값을 쓰지 않고 OOF에서 정합니다. 공식 validation은 동결 후 평가에만 씁니다.
- **방법은 선행 연구 먼저:** 방법을 정하기 전에 근거 논문을 확인해 기록하고, 직접 근거가 약한 부분은 "근거 약함"으로 표시합니다.
- **가짜 라벨 금지:** 라벨이 없으면 규칙으로 만들어 쓰지 않고 검수를 전제로 합니다.
- **버린 것도 기록:** 효과가 없던 시도(예: 물건 새로 등장 AND 조건, 프레임 차이 특징, 손 크롭, 사건 직전·직후 정상 제외)와 이유를 남겼습니다.
