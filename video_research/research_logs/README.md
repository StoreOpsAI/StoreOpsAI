# 연구 과정 기록

`../의사결정_정리.md`, `../행동인식_분석.md`가 가리키는 평가 로그와 정상 창 검수 기록입니다. 가중치와 영상은 없습니다.

| 폴더 | 내용 |
|---|---|
| `eval_logs/` | 평가 로그: 6클래스 기준선 A(`six_A_full_eval.log`), 직전·직후 제외 비교(`six_A_cmp_pre48.log`, 채택하지 않음), 손 크롭·관절 결합 OOF, 유기 게이트, 야간 요약 |
| `official_val/` | 공식 validation 평가 보고(동결 후)와 학습–검증 차이 표. 공식 validation은 여러 번 봐서 blind 평가가 아니다 |
| `normal_audit/` | **정상 창 검수 기록**(장소별 CSV). 판정자는 Claude 시각 검수이며 **사람 검수가 아니다**(`reviewer` 열). 제외 사유: D 물건·음료 만짐, C 숙임·카운터 조작, R 사건 흔적, S 선반 앞 손 동작 판별 불가, A 앉기, E 사람이 안 보임 |
| `normal_audit/tools/` | 검수 시트를 만들고 판정을 기록한 스크립트와 상태(`audit_state.json`), 장면 목록(`index_*.csv`) |

검수 시트 이미지(영상 프레임)는 얼굴이 보일 수 있어 올리지 않았다.
